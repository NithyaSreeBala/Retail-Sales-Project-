# Retail Sales Data Analysis Project

## Project Overview
This project analyzes retail sales data and builds a prediction model using machine learning.

## Features
- Data Cleaning
- Exploratory Data Analysis
- Data Visualization
- Machine Learning Prediction

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Workflow
1. Load Dataset
2. Clean Data
3. Analyze Trends
4. Visualize Insights
5. Build Prediction Model

## Results
The project identified important sales trends and created a predictive model for sales forecasting.
